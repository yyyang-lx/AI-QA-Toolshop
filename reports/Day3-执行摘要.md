# Toolshop 测试执行摘要

## 1. 测试概况

- **测试项目：** Toolshop 电商 Web 系统
- **测试环境：** With Bugs 版本在线演示网站
- **测试类型：** Web 功能测试、异常场景测试、边界值测试
- **测试方式：** 手工测试为主
- **测试对象：** 商品搜索、分类筛选、商品详情、购物车、注册与登录页面
- **测试目的：** 验证核心业务功能是否符合预期，识别功能异常及潜在质量风险。

## 2. 测试执行情况

本轮测试围绕商品浏览与购物车核心流程展开，主要覆盖以下内容：

1. **商品搜索：** 验证正常关键词搜索、无结果搜索、带空格的关键词搜索及切换搜索关键词等场景。
2. **商品分类筛选：** 验证分类筛选、取消筛选、切换分类及分类与关键词组合筛选。
3. **商品详情：** 检查商品名称、价格、图片、购买数量及加入购物车功能。
4. **购物车：** 验证商品添加、重复添加、数量修改、金额计算、商品删除、页面刷新后的购物车状态。
5. **注册与登录页面：** 检查页面展示、表单输入及部分登录异常场景。由于账号创建状态尚未完全确认，暂不对完整注册登录流程下结论。
6. **边界与异常场景：** 检查购物车数量为 0、负数、小数及非数字输入时的系统表现。

测试结果以测试用例记录中的实际执行结果为准。对于尚待确认的场景，暂不直接判定为产品缺陷。

## 3. 主要测试发现

本轮测试发现以下值得关注的异常：

| 编号 | 异常现象 | 初步影响 |
|---|---|---|
| BUG-001 | 添加商品后页面提示 `Oops, something went wrong.`，但商品实际已加入购物车 | 操作反馈与实际执行结果不一致 |
| BUG-002 | 购物车商品行内金额显示为 `$00.00`，但底部总价计算正确 | 商品金额展示不准确，可能影响用户核对金额 |
| BUG-003 | 点击购物车商品右侧的删除按钮后，商品没有移除 | 用户可能无法按预期删除商品 |
| BUG-004 | 重复添加购物车中已有的商品时出现错误提示，数量没有增加 | 影响重复添加商品的操作 |
| BUG-005 | 注册后使用相同凭据登录失败 | 账号是否创建成功尚未确认，需要进一步核实 |
| BUG-006 | 商品数量调整为 0 后，购物车入口消失 | 用户可能无法通过购物车入口继续查看或修改购物车 |

以上为测试过程中记录的异常现象。具体原因尚未定位，部分问题仍需进一步复现或结合产品需求确认。

## 4. 已验证的正常表现

- 商品搜索能够返回匹配结果；搜索不存在的关键词时能够显示无结果状态。
- 商品分类筛选及分类与关键词组合筛选能够返回符合条件的商品。
- 商品详情页展示了商品名称、价格等信息，列表与详情中的对应信息一致。
- 购物车底部总价在已验证的数量修改场景下能够正确计算。例如，Combination Pliers 单价为 $14.15，数量为 2；Pliers 单价为 $12.01，数量为 1，底部总价为 $40.31。
- 刷新页面后，已添加商品及其数量能够保留。
- 部分数量边界场景表现符合预期，例如输入小数数量后，系统将数量恢复为整数。

以上结论仅适用于已实际执行的测试场景，不代表相关模块的所有功能均已验证通过。

## 5. 测试限制与遗留风险

1. 当前使用在线演示环境，无法控制服务端状态、测试数据及环境变更。
2. 注册账号的创建结果尚未完全确认，因此注册登录流程的验证范围有限。
3. 本轮以手工功能测试为主，尚未完成系统化的接口自动化回归。
4. 已发现异常的根本原因尚未定位，仍需进一步复现并确认。
5. 当前测试覆盖范围有限，尚不能据此判断系统整体质量或生产环境下的稳定性。

## 7. 阶段性结论

本轮测试完成了 Toolshop 主要商品浏览功能及购物车核心场景的初步验证，并记录了多项值得进一步确认的异常。测试过程不仅关注功能是否能够执行，也关注页面提示与实际状态是否一致、金额计算是否正确，以及异常输入下系统的表现。

当前结果属于阶段性测试结论。后续需要继续核实缺陷、补充自动化验证，并结合完整测试记录形成最终质量评估。
